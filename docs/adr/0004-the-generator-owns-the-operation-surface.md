# Генератор владеет поверхностью операций

Генератор по спецификации YouTrack строит только поверхность операций: URL, параметры и сборку запроса. Тела
пишутся вручную, потому что они деревья ([ADR-0001](0001-a-response-is-a-tree.md)).

## Решение

- **`oapi-codegen` запускается с `models: true` и `client: true`, а `client-with-responses.tmpl` заменён
  заглушкой.** Остаётся сырой `Client` с `*http.Response` и `<Op>Params`, тела уходят через `<Op>WithBody`.
  `models: true` нужен ради `Params`.
- **`internal/ytapi` — только выход генератора, и импортирует его один файл-адаптер `internal/youtrack/ytapi.go`.**
  За пределами адаптера видны только `Client`, `NewClient`, `*Params`, `RequestEditorFn` и `HttpRequestDoer`
  ([ADR-0006](0006-packages-and-the-entry-point.md)).
- **Спецификация — `api/openapi.json`, её снимает `make openapi` с запиненного дев-инстанса.** Вручную её не правят.
- **Спецификацию правит один overlay `api/overlay.yaml` со `strict: true`.** Схем он не добавляет. Виды записей:
  - `x-go-name` на `IssueWorkItem…properties.type`, потому что иначе `type` и `$type` оба становятся полем `Type`;
  - `operationId`, только если сгенерированное имя неверно или нечитаемо, и не совпадая с чужим;
  - исправление объявленного параметра;
  - параметр, который сервер понимает, а спецификация не объявляет: только измеренный, на вызываемой операции и
    записанный в ADR с версией YouTrack. `update` такой записи — массив, потому что объект заменил бы массив
    параметров целиком.
- **`customFields=` отправляется, только если блок самой задачи — единственный блок кастом-полей в запросе**, потому
  что сервер обрезает этим параметром все блоки ответа. Иначе блоки приходят целиком, а поля выбираются при печати.
- **Неверный медиатип исправляется в месте вызова.** `POST /articles/{id}/attachments` уходит multipart, как у
  задачи, потому что на JSON сервер отвечает `500`.
- **Регенерацию проверяют утверждения, а не код возврата генератора**, потому что генератор выходит с 0 и на битом
  выходе. `make ytapi` проверяет, что пакет собирается, выход байт в байт воспроизводится из запиненных входов,
  `ClientWithResponses` нет, в `ClientInterface` не меньше 335 методов, а `internal/ytapi` виден только из адаптера
  (`scripts/ytapi-imports.go`).
- **Исправления в коде не помечаются.** Каждое утверждение о сервере записано в ADR вместе с версией YouTrack, на
  которой измерено. Измеряют на дев-инстансе (`dev/`), а тестов против него нет
  ([ADR-0006](0006-packages-and-the-entry-point.md)).

## Отвергнуто

- **`ClientWithResponses` и типизированные тела.** Сгенерированная структура не умеет очистить поле.
- **Скрипт правок спецификации вместо overlay.** Правки нужны были только сгенерированным телам.
- **`RequestEditorFn`, дописывающий необъявленный параметр.** Не заметит, когда спецификация его объявит.
