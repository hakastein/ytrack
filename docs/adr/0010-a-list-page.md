# Список берёт любую страницу, а `--limit` — только там, где страница бывает

Вызывающему нужно дойти до любой записи списка, а сузить запрос можно не у каждого списка.

## Решение

- **Каждый список, чей запрос принимает `$skip`, берёт `--skip N` рядом с `--limit`.** N — от 0 до `2^31 − 1`,
  `$skip=0` не отправляется. Пропуск за конец даёт пустую страницу, а не ошибку.
- **`total` — размер всего результата запроса на любой странице, `truncated` — `total > skip + returned`.**
  Непустая страница короче лимита даёт `total = skip + returned` без подсчёта. У `activity list` `total: null`, а
  обрезку доказывает активность сверх лимита ([ADR-0003](0003-output-is-one-yaml-document.md)).
- **`article list --parent <id>` перечисляет дочерние статьи, а с `--query` даёт `bad_usage`.**
- **`link list` и `field list` не берут `--limit` и печатают всё,** потому что страницу у них не запросить.
- Записи, добавленные или удалённые между страницами, сдвигают следующую страницу, потому что курсора YouTrack не
  держит.
- Подсчёт меньше `skip + returned` — это `upstream_failed`, записей больше лимита — `upstream_invalid`.
