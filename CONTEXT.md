# ytrack

CLI для YouTrack, рассчитанный на агента. Здесь слова, которыми о нём говорят решения, комментарии и тесты.
Термин называется так же, как в коде, в API YouTrack или в cobra.

## Язык

### SDK

**SDK** (`github.com/hakastein/go-youtrack`, пакет `youtrack`):
Go SDK YouTrack, на котором стоит ytrack. Его слова — владелец, внутренний и читаемый id, выражение полей, поля по
умолчанию, документ, узел (`youtrack.Node`), многострочный текст, страница, свободный текст, кастом-поле, бандл,
ключ значения, метаданные проекта, кэш метаданных, фраза связи, запись времени, проверка записи, код, после записи,
предупреждение (`youtrack.Warning`) — определены в его
[`CONTEXT.md`](https://github.com/hakastein/go-youtrack/blob/main/CONTEXT.md), и ytrack говорит ими так же.
_Avoid_: библиотека, модуль youtrack, клиент (без уточнения)

### Команды

**Команда** (command):
Узел дерева cobra: `issue`, `issue show`, `auth login`. Встроенная команда названа по объекту YouTrack, над которым
работает.
_Avoid_: сущность, группа, ресурс

**Подкоманда** (subcommand):
Команда под другой командой: `show` в `issue show`. У встроенных команд, кроме `auth`, это `show`, `list`,
`create`, `update`, `delete`, `add` и `remove`.
_Avoid_: глагол, действие, операция

**Путь команды** (command path):
Слова вызова до аргументов: `issue show`. У скрипта команды — путь его файла в корне скриптов.
_Avoid_: имя команды

### Адрес и токен

**Вход** (login):
Адрес инстанса и токен к нему, взятые вместе из одного источника.
_Avoid_: учётные данные, credentials, профиль

**Запись входа** (login record):
Вход в `~/.ytrack/auth.json`, сохранённый `auth login`. Запись без области — глобальная.
_Avoid_: конфиг, сохранённый токен

**Область** (`scope`):
Каталог, в котором действует запись входа, вместе со всем, что под ним.
_Avoid_: контекст, рабочая область, префикс пути

**Источник входа** (`auth_from`):
Откуда взят вход: `environment` или `settings`.
_Avoid_: происхождение, origin

### Связи

**Целевая задача** (target):
Задача на другом конце связи от той, которую вызывающий назвал первой.
_Avoid_: партнёр, вторая задача

### Учёт времени

**Тип работы** (work item type):
Вид работы в записи времени, например «Разработка». Набор типов у каждого проекта свой.
_Avoid_: категория работ, activity type

### Вложения

**Вложение** (attachment):
Файл, приложенный к задаче или статье. Файл комментария — вложение его задачи.
_Avoid_: аттач, документ

**Подписанная ссылка** (signed link):
`url` вложения с подписью, по которому файл отдаётся без токена, пока подпись не истекла.
_Avoid_: прямая ссылка, временная ссылка

### Теги

**Тег** (tag):
Метка задач и статей. Тег принадлежит пользователю (`owner`), и имя тега однозначно только вместе с ним.
_Avoid_: метка, label, ярлык

**Доступ к тегу** (tag sharing):
Три набора групп: кто видит тег, кто вешает, кто правит — `--visible-for`, `--taggable-by`, `--updateable-by`.
_Avoid_: `visibleFor` как весь доступ, шеринг

### Активности

**Активность** (activity):
Одно изменение задачи: когда, кто, какой категории, что добавило и что убрало. У статьи активностей нет.
_Avoid_: журнал, запись журнала, событие, история

**Категория активности** (activity category):
Вид изменения: `CustomFieldCategory`, `CommentsCategory` и другие. По категориям `activity list` сужается.
_Avoid_: категория журнала, тип события

**Коммит** (VCS change):
Изменение в репозитории, которое YouTrack привязал к задаче: активность категории `VcsChangeCategory`.
_Avoid_: VCS-изменение, пуш, MR

### Диагностика

**Ошибка** (`diag.Fault`):
Документ в stderr о том, что команда не выполнена или неизвестно, выполнена ли. Первый ключ — `code`. Ошибку SDK
(`youtrack.Error`) несёт один к одному.
_Avoid_: отказ, refusal

### Оболочка и бинарник

**Скрипт автодополнения** (completion script):
Скрипт оболочки, который печатает `ytrack completion` и который на каждый TAB спрашивает подсказки у ytrack.
_Avoid_: скрипт (без уточнения: так зовётся скрипт команды)

**Протокол автодополнения** (`__complete`):
Скрытый вызов cobra, которым скрипт автодополнения спрашивает подсказки к набранной строке.
_Avoid_: скрытая команда

**Ревизия** (`revision`):
Коммит, из которого собран бинарник. Её печатает `ytrack --version`.
_Avoid_: версия сборки, номер сборки

**Релиз** (release):
Сборка коммита из `main`, выложенная в GitHub Releases с календарной версией.
_Avoid_: дистрибутив, выпуск

### Скрипты команд

**Скрипт команды** (command script):
Модуль на JavaScript, которым написана команда. Встроенные команды — тоже скрипты команд, вшитые в ytrack.
_Avoid_: скрипт (без уточнения), плагин, расширение

**Объявление команды** (`exports.command`):
Литерал в скрипте команды: `short`, `long`, аргументы, флаги с их типами, `choices` и `default`. Справка и
подсказки строятся по нему, не выполняя скрипт.
_Avoid_: манифест, сигнатура

**Корень скриптов** (script root):
Каталог, в котором путь файла становится путём команды: `.ytrack/scripts` проекта или `~/.ytrack/scripts`.
_Avoid_: каталог плагинов, путь поиска

**Библиотечный модуль** (library module):
Модуль корня скриптов без `exports.command`: код, общий для скриптов этого корня.
_Avoid_: хелпер, утилиты

**API скриптов** (`ytrack/v<N>`):
Всё, что ytrack даёт скрипту команды: функции команд, `fs` и `http`.
_Avoid_: SDK, рантайм

**Функция команды** (command function):
Функция API скриптов, которая делает то же, что встроенная команда, и отвечает её документом: `issue.show` для
`issue show`.
_Avoid_: функция глагола, метод, эндпойнт

**Версия API** (API version):
`N` в `ytrack/v<N>`. С версией релиза не связана.
_Avoid_: версия ytrack, версия скрипта
