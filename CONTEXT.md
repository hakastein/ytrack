# ytrack

CLI для YouTrack, рассчитанный на агента. Здесь слова, которыми о нём говорят решения, комментарии и тесты.

## Язык

### Вызов

**Имя команды** (command name):
Слова вызова до аргументов. У встроенной команды это сущность и глагол, у скрипта команды из корня — путь его
файла.
_Avoid_: подкоманда, путь команды

**Сущность** (entity):
Первое слово имени встроенной команды — то, над чем она работает: задача, статья, комментарий.
_Avoid_: ресурс, объект, группа команд

**Глагол** (verb):
Второе слово имени встроенной команды — что делается с сущностью. Словарь закрыт: `show`, `list`, `create`,
`update`, `add`, `remove`, `delete`.
_Avoid_: операция, подкоманда

**Владелец** (owner):
Задача или статья, которой принадлежат комментарии, вложения и теги.
_Avoid_: родитель, хозяин, родительская сущность, задача-или-статья

**Форма идентификатора** (identifier form):
Чем оказалась строка, которой назвали сущность: читаемым идентификатором задачи, статьи, внутренним id или ничем.
_Avoid_: формат id, тип идентификатора, разбор id, валидация идентификатора

**Внутренний id** (internal id):
Идентификатор вида `7-12`, который инстанс даёт любой своей сущности. У дочерней сущности без читаемого
идентификатора это единственный адрес.
_Avoid_: id сущности, entity id, числовой id, короткий id, id базы

**Поля по умолчанию** (default fields):
Набор полей, который команда запрашивает, если вызывающий не задал свой.
_Avoid_: дефолт-рекомендация, стандартный набор, все поля

### Поиск

**Выборка** (selection):
Задачи, которые находит один запрос на языке YouTrack. Команда печатает одну её страницу.
_Avoid_: поиск, фильтр, результат запроса, список задач

**Свободный текст** (free text):
Части запроса, которые сервер не распознал как поле, значение или оператор и ищет как текст в задачах.
_Avoid_: текстовый поиск, полнотекст, неразобранная часть

### Адрес и токен

**Запись входа** (login record):
Адрес инстанса и токен к нему, сохранённые командой `auth login`. Запись без области — глобальная.
_Avoid_: конфиг, профиль, учётные данные, сохранённый токен

**Область** (scope):
Каталог, в котором действует запись входа, вместе со всем, что под ним.
_Avoid_: контекст, рабочая область, префикс пути, окружение

**Происхождение** (origin):
Откуда взят вход: из окружения или из записей входа.
_Avoid_: источник, provenance, место токена

### Ответ

**Дерево** (tree):
Ответ YouTrack или тело запроса в том виде, в каком они получены или отправляются. Отсутствующий ключ, `null`, `""` и
`[]` в нём различаются.
_Avoid_: структура, модель, JSON

**Каталог схем** (schema catalogue):
Схемы спецификации YouTrack, которые ytrack несёт в себе, чтобы проверять ключи, которых нет в ответе.
_Avoid_: спека, модели, словарь полей

**Нормализация** (normalisation):
Шаг, на котором дерево становится тем, что печатается: выбираются ключи значений, порядок ключей и форма времени.
_Avoid_: рендеринг, форматирование, постобработка

**Узел** (node):
Единица печатаемого документа, которая знает свой вид: null, скаляр, многострочный текст, список или отображение.
_Avoid_: узел дерева, нормализованное дерево, нода

**Многострочный текст** (multi-line text):
Узел для текста, который читает человек: описание задачи, текст комментария, содержимое статьи. Печатается
построчно и байт в байт.
_Avoid_: проза, многострочная строка, markdown

**Ключ значения** (value key):
То, чем называют значение и при чтении, и при записи: `login` у пользователя, `name` у значения из набора.
_Avoid_: идентичность, идентификатор, подпись, отображаемое имя

### Кастом-поле

**Метаданные поля** (field metadata):
Что проект знает о своём кастом-поле кроме значения: имена, тип, кратность, обязательность и допустимые значения.
_Avoid_: описание поля, схема поля, настройки поля

**Источник допустимых значений** (values source):
Откуда берутся значения, которые принимает поле. Пустой источник значит «без ограничения».
_Avoid_: бандл, справочник, список значений

**Кэш метаданных** (metadata cache):
Метаданные полей, сохранённые между вызовами для одной пары адреса и токена. Кэш может подтвердить имя, но не
отвергнуть.
_Avoid_: локальная копия, снимок, состояние

### Связи

**Фраза связи** (link phrase):
Имя связи в одном направлении: `A "depends on" B`. Единственное имя связи, которое видит и пишет вызывающий.
_Avoid_: тип связи, направление связи

**Партнёр** (partner):
Задача на другом конце связи от той, которую вызывающий назвал первой.
_Avoid_: цель, target, вторая задача

### Учёт времени

**Запись времени** (work item):
Время, потраченное на задачу: длительность, день, тип работ, текст и автор. Бывает только у задачи.
_Avoid_: ворклог, трудозатраты, списание времени, затраченное время

**Тип работ** (type of work):
Вид работы в записи времени, например «Разработка». Набор типов у каждого проекта свой.
_Avoid_: категория работ, вид работ, activity type, кастом-поле типа

### Вложения

**Вложение** (attachment):
Файл, приложенный к задаче или статье. Файл комментария — вложение его задачи.
_Avoid_: файл, аттач, приложение, документ

**Подписанная ссылка** (signed link):
Адрес вложения, по которому файл отдаётся без токена, пока не истёк срок.
_Avoid_: ссылка на файл, url вложения, прямая ссылка, временная ссылка

### Теги

**Тег** (tag):
Метка задач и статей вместе с пользователем, которому она принадлежит. Имя тега однозначно только в паре с
владельцем.
_Avoid_: метка, label, ярлык, категория

**Доступ к тегу** (tag sharing):
Три отдельных набора прав на тег: кто его видит, кто вешает, кто правит.
_Avoid_: `visibleFor` как вся видимость, права на тег, шеринг

### Журнал задачи

**Журнал** (activity journal):
Все изменения одной задачи, новые первыми. У статьи журнала нет.
_Avoid_: история, лог, лента, активности

**Запись журнала** (activity):
Одно изменение задачи: когда, кто, какой категории, что добавило и что убрало.
_Avoid_: активность, событие, действие, запись истории, ревизия

**Категория журнала** (activity category):
Вид изменения в журнале. По категориям журнал можно сузить.
_Avoid_: тип активности, вид события, фильтр истории

**Коммит** (VCS change):
Изменение в репозитории, которое YouTrack привязал к задаче. В журнале это запись категории `VcsChangeCategory`.
_Avoid_: VCS-изменение, ревизия, пуш, MR

### Запись

**Запись-замена** (whole-set write):
Запись многозначного поля целиком: вызывающий перечисляет весь набор, который должен остаться.
_Avoid_: обновление поля, добавление значения, частичная запись

**Сверка записи** (write check):
Сравнение каждого записанного поля с ответом на запись. Расхождение — ошибка.
_Avoid_: перечитывание, подтверждение записи

**Неопределённость записи** (write uncertainty):
Запрос отправлен, ответ не получен, и неизвестно, состоялась ли запись.
_Avoid_: таймаут, сбой записи, неизвестная ошибка

### Диагностика

**Ошибка** (error):
Документ в stderr о том, что команда не выполнена или неизвестно, выполнена ли. Первый ключ — код из закрытого
словаря.
_Avoid_: отказ, исключение

**Предупреждение** (warning):
Документ в stderr о том, что вызывающему стоит знать, но что результата не отменяет.
_Avoid_: варнинг, лог, замечание

### Оболочка и бинарник

**Скрипт автодополнения** (completion script):
Текст для оболочки, который печатает `ytrack completion` и который на каждый TAB спрашивает подсказки у ytrack.
_Avoid_: автокомплит, completion, дополнялка, shell-скрипт

**Протокол автодополнения** (completion protocol):
Скрытый вызов, которым скрипт автодополнения спрашивает у ytrack подсказки к набранной строке.
_Avoid_: скрытая команда, `__complete`, ответ cobra, динамическое дополнение

**Ревизия сборки** (build revision):
Коммит, из которого собран бинарник. Её печатает `ytrack --version`.
_Avoid_: версия сборки, билд, номер сборки, хеш

**Релиз** (release):
Сборка коммита из `main`, выложенная в GitHub Releases с календарной версией.
_Avoid_: билд, дистрибутив, выпуск

### Скрипты команд

**Скрипт команды** (command script):
Модуль, которым написана команда. Встроенные команды — тоже скрипты команд, только вшитые в ytrack.
_Avoid_: скрипт (без уточнения: так зовётся скрипт автодополнения), плагин, расширение, макрос, процедура

**Объявление команды** (command declaration):
Неизменяемое описание команды внутри её скрипта: аргументы, флаги и допустимые значения. Справка и подсказки
строятся по нему, не запуская скрипт.
_Avoid_: манифест, метаданные, сигнатура, конфиг команды

**Корень скриптов** (script root):
Каталог, в котором путь файла становится именем команды: корень проекта или корень пользователя.
_Avoid_: путь поиска, каталог плагинов, папка скриптов, источник

**Библиотечный модуль** (library module):
Модуль корня скриптов без объявления команды: код, общий для скриптов того же корня.
_Avoid_: хелпер, утилиты, общий код, стандартная библиотека

**API скриптов** (script API):
Всё, что ytrack даёт скрипту команды: функции глаголов, файлы и HTTP.
_Avoid_: SDK, биндинги, рантайм, внутреннее API

**Функция глагола** (verb function):
Часть API скриптов, которая делает то же, что команда глагола, и отвечает её документом.
_Avoid_: операция, метод, эндпойнт, вызов API

**Версия API** (API version):
Номер, по которому скрипт выбирает, против какого API скриптов он написан. С версией релиза не связан.
_Avoid_: версия ytrack, версия релиза, версия скрипта
